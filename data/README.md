# BeanTrack – Dataset Documentation

## 1. Overview
This folder contains the dataset used for the development and testing of the BeanTrack: Smart Cafe Operations and Inventory Management System.

The dataset provides sample cafe sales and product information that will help demonstrate how the system records transactions and analyzes sales.

## 2. Data Source
- **Dataset name:** Anonymous Transactional Dataset V2
- **Source:** Mendeley Data
- **Link:** https://data.mendeley.com/datasets/kcgf45y24m/2
- **DOI:** https://doi.org/10.17632/kcgf45y24m.2
- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0)

## 3. Files Included

| File | Description |
|---|---|
| `Products.csv` | Contains product information, including product names, categories, variants and prices. |
| `Transactions.csv` | Contains cafe transaction records, including dates, sales amounts, products sold and payment methods. |

## 4. Dataset Information
The dataset contains:
- 53,820 transaction records.
- 96 product records.
- Sales information from three outlets.
- Transaction dates covering January to September 2025.

## 5. How the Dataset Will Be Used
The dataset will be used to:
- Test sales recording and reporting.
- Identify popular products.
- Calculate sales totals.
- Demonstrate transaction processing in Oracle Database 21c and PL/SQL.

## 6. Dataset Limitations
The original dataset does not contain ingredient quantities, recipes, supplier details, purchase orders or stock records.

These additional records will be created using clearly labelled test data or obtained from authorized cafe records. They will not be presented as part of the original dataset.
